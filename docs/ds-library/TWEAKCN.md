# TweakCN · Library V1.1

Jediný katalog: https://iriskax.github.io/axolotl-preview/ds-library-v1-1/#design-system

- Kanonické hodnoty: `src/design-system/tokens/tweakcn.export.css`, přesná příloha uživatelky včetně OKLCH, obou témat, fontů, radius, spacing a stínů. `theme.ts` skládá tento export s osmi minimálními, výslovně povolenými korekcemi v `contrast-corrections.json` do jediného registru. Původní export zůstává beze změny. Tailwind direktivy a samoodkazující compiler aliasy se nepřenášejí jako globální CSS.
- `src/design-system/theme/` mapuje sémantické role na skutečné stávající komponenty. Aktivuje se pouze v `library.html`. Původní produkční tokeny a implementace Headeru se nemění. Pozůstalé `--ds-*`, `--axo-*`, `--pn-*` a `--pg-*` jsou v katalogu adaptéry jednoho theme, nikoli nové palety.
- Header a katalog používají společné Preferences. Vnořené ukázky Themes zachovávají vlastní light/dark pro srovnání včetně portálů. Bento oblasti, umístění Office, šest widgetů, dropdown/hover/focus logika a Star Border zůstávají.
- Brandové O2 Blue, Axolotl Violet, osm gradientů a Mascot V3 jsou zachované samostatně. Chart 1–5 jsou přesné datové role exportu; nepoužívají se jako náhradní success/warning paleta.
- Montserrat a Fira Code se načítají z lokálních WOFF2 (Latin + Latin Extended), zdroj Fontsource 5.3.0, licence SIL OFL 1.1 uložené u fontů. Georgia je podle rozhodnutí uživatelky pouze systémový font. Foundations ukazuje její skutečnou dostupnost; webfont bez licence se nešíří.
- Export nemá success/warning barvy. Dosavadní význam zachovávají text a ikony; text používá foreground. Chyby používají destructive. Korekce upravují light muted-foreground, accent-foreground, sidebar-accent-foreground, destructive a input; dark primary-foreground, muted-foreground a input. Hue i chroma zůstávají kromě neutrálního bílého inkoustu zachované.

Kontrola: `node scripts/ds-library/build.mjs`, registry test a `node scripts/ds-library/check-theme.mjs` proti Vite preview na 4185. Skript ověřuje účinné hodnoty obou témat, skutečně načtené fonty, všechny rodiny, nativní Dashboard, Header/menu/focus/URL/mobil a Star Border. Kontrastní nálezy jsou blokující. `node scripts/ds-library/check-contrast.mjs` prochází skutečný registr v light/dark: lazy stránky, varianty, hover/active/focus, loading/disabled, validaci, vybrané položky, otevřené portály, Header včetně mobilu. Měří computed barvy s kompozicí alfa, nativní hranice z pixelů a skutečná pozadí textu na všech brandových plochách ze screenshotů; nepoužívá průměry gradientů. Výstup je krátký, podrobnosti pouze v `/tmp/axolotl-contrast-results.json`. Historický `compare-dashboard.mjs` ověřoval původní vzhled 523c983 a po výslovně zadané změně theme již není release gate.

Žádný merge do main, změna produkční aplikace, shadcn kopie ani nový katalog.

Společné opravy stavů: Button má jednoho vlastníka dvojice pozadí/text, včetně hover, active, pressed a loading. Header rozlišuje aktivní položku neprůhledným primary párem a zatržítkem. Inset focus menu používá inkoust svého povrchu; vnější focus používá ring. Progress používá ring proti muted, slider input pro hranu. Segmented má čitelný spodní indikátor výběru; loading InteractiveCard neztrácí čitelnost sníženou průhledností. Brandové gradienty a bezpečné podklady popisků se nemění. Nativní radio/slider byly ověřené v Chromium; jejich vykreslení závisí také na prohlížeči. Jde o automatickou regresní kontrolu a vizuální revizi katalogu, nikoli certifikaci celého produktu.

Button System V1 extends the canonical `Button` with Outline and composes `SplitButton` from the same export (no new dependency). `--button-radius` is `radius-md + 2px`, capped below half the compact button height; other component radii are unchanged. The Buttons category contains S/M/L, real pointer/keyboard states, loading/disabled, export menu and confirmation examples. All seven types remain design drafts. The existing contrast gate covers Outline, Split menu navigation/focus, and stable loading dimensions.
