# Header brand mark

Only the O₂ artwork supplied in the user's Canva board is used in the header:
https://www.canva.com/design/DAHXPK5WIHI/9qpN5X9M0oFjbj42W2Ssfw/edit

`o2-mark.svg` embeds the original transparent PNG reference in a luminance mask. The app applies its foreground color: white in dark mode and dark in light mode. There is no runtime dependency on Canva.

The visible mark is 26 × 26 px inside a 32 × 32 px link, aligned with the other header controls. No axolotl symbol or wordmark is displayed.
