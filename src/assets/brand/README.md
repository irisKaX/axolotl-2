# Axolotl header logo

Compact lockup assembled from the O₂ and axolotl artwork supplied in the user's Canva board, inspected on 2026-10-15:
https://www.canva.com/design/DAHXPK5WIHI/9qpN5X9M0oFjbj42W2Ssfw/edit

The original transparent PNG references are embedded in the SVGs. Luminance masks keep the face details transparent and let the app apply its foreground color in either theme. No remote Canva URL is required at runtime. These are compact screen assets, not print vector masters.

`axolotl-logo.svg` contains the full lockup. `axolotl-symbol.svg` is the compact axolotl used below 600px. Both have transparent backgrounds and a white fill; the header applies them as CSS masks.
