# Office artwork

Generated production layers based on the user-approved Creative Studio B concept, 16 October 2026. The original user-supplied premium Axolotl character defines all sprites. No remote image requests are needed at runtime.

- office-room.webp: aligned day/night panorama, without characters. Brumlovka/Balance Club left, Filadelfie and Beta outside; Gamma/O2 excluded.
- office-seated.webp: 3 columns (front, side, right), 4 rows (typing A/B, mug lowered/raised), transparent.
- office-walk.webp: 4×2 transparent atlas: four walk phases, then standing mug lowered/raised, looking out, idle.
- office-laptop.webp: user-supplied transparent seated laptop pose.

WebP encoding only optimizes the generated/source artwork. Geometry and furniture occlusion are defined in LivingOffice.css; character activity is controlled independently in office-activity.ts.
